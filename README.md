# ET4132 Group 10 – CroMaccy's Restaurant Site

A PHP + MySQL website for a takeaway menu: a home page, a menu display page, and a page for adding menu items.

- `src/` – the site (`Home.html`, `menu_display_page.php`, `add_item_page.php`, `db_connect.php`)
- `database.sql` – database schema and sample data
- `docs/Presentation.pptx` – project presentation

## Run locally
1. Install XAMPP (or any PHP + MySQL stack).
2. Import `database.sql` into MySQL (creates `db_et4132_group10`).
3. Copy `src/` into `htdocs` and open `Home.html`.
